# Run the Phase 2 experiment on your computer

This experiment uses the included saved modality-distance CSV. It does **not** retrain MABAD and does **not** need `imputer.pkl`.

## macOS / Linux (bash or zsh)

```bash
cd phase2_reliability_candidate
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install numpy pandas scikit-learn
python phase2_extended.py
```

If you use fish shell, activate with `source .venv/bin/activate.fish` if generated by your Python version; otherwise use bash/zsh for the activation command. If activation gives shell syntax errors, run the script directly with `.venv/bin/python phase2_extended.py` after installing dependencies via `.venv/bin/python -m pip install numpy pandas scikit-learn`.

## Windows PowerShell

```powershell
cd phase2_reliability_candidate
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install numpy pandas scikit-learn
python phase2_extended.py
```

## Expected output files

- `outputs/extended_validation_summary.csv` — main comparison table; start here.
- `outputs/extended_validation_fold_metrics.csv` — all fold-level metrics and fold-fitted weights.
- `outputs/extended_test_exploratory.csv` — test scores for transparency only; do not use to select a method.
- `outputs/extended_run_metadata.json` — counts, years, IQRs, and limitations.

Send the complete terminal output and these files: `extended_validation_summary.csv`, `extended_validation_fold_metrics.csv`, and `extended_run_metadata.json`. Do not send private data; the included CSV contains project research data already used for this experiment.
